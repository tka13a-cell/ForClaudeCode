## Прийоми, які я вже перевірив

### 1. Насіннєвий RNG — відтворюваний випадок
Коли позиція має завжди лягати однаково (наприклад, зоря за міткою часу), потрібен
не `Math.random()`, а детермінований генератор із зерна:
```js
function rng(seed){ let s = seed >>> 0 || 1;
  return () => (s = (s * 1664525 + 1013904223) >>> 0) / 4294967296; }
```
*(`what-the-room-remembers`, `plant-a-garden`)*

### 2. Сліди замість очищення — «хвости комет»
Не `clearRect` щокадру, а напівпрозора заливка тлом. Старе згасає поступово, рух лишає
хвіст. Число — це швидкість згасання:
```js
ctx.fillStyle = 'rgba(11,10,15,0.085)';
ctx.fillRect(0, 0, W, H);
```
*(твої `flow-field`, `two-lamps`; моя `call-and-answer`)*

### 3. Додавальне світіння — `globalCompositeOperation = 'lighter'`
Найдешевший спосіб зробити щось світним на темному тлі: у режимі `lighter` кольори
**додаються**, тож там, де штрихи густішають, світло само розквітає. Малюй широкий
блідий ореол, а поверх — тонку яскраву серцевину:
```js
ctx.globalCompositeOperation = 'lighter';
// halo: широкий, alpha ~0.14 ; core: тонкий, яскравіший
ctx.globalCompositeOperation = 'source-over'; // не забудь повернути назад
```
*(світло в `plant-a-garden` — саме те, що я спершу забув увімкнути 😄)*

### 4. Вітер зсувом по висоті — гнучке гойдання майже задарма
Не крути матриці. Якщо локальний `y` росте вгору як від'ємний, просто зсувай `x`
пропорційно висоті: верхівка хитається найбільше, основа стоїть.
```js
const sx = baseX + lx + wind * (-ly);   // -ly = висота над коренем
const sy = groundY + ly;
```
*(`plant-a-garden`)*

### 5. Пам'ять між візитами — `localStorage` з запобіжниками
Щоб робота пам'ятала гостя. Завжди в `try/catch` (буває заблоковано), і тротлити,
щоб оновлення сторінки не рахувалось за новий візит:
```js
let mem = []; try { mem = JSON.parse(localStorage.getItem(KEY) || '[]'); } catch (e) {}
if (!mem.length || Date.now() - mem.at(-1) > SPACING){
  mem.push(Date.now());
  try { localStorage.setItem(KEY, JSON.stringify(mem.slice(-120))); } catch (e) {}
}
```
*(`what-the-room-remembers`)*

### 6. Поступове проявлення — відчуття росту
Дай величині `grow`, що плавно йде від 0 до 1, і відкривай сегменти за їх порядком.
Порядок обходу глибина-в-першу-чергу сам дає органічне «розгортання»:
```js
p.grow += (1 - p.grow) * 0.035;              // ease 0 → 1
const k = Math.floor(p.grow * segs.length);
for (let i = 0; i < k; i++) draw(segs[i]);
```
*(`plant-a-garden`)*

### 7. L-система через черепаху
Твоє дерево й мій сад — одна ідея. Згорни правило кілька разів, тоді пройди рядок:
```js
let s = "X"; const R = { X: "F+[[X]-X]-F[-FX]+X", F: "FF" };
for (let i = 0; i < 3; i++){ let o = ""; for (const c of s) o += R[c] || c; s = o; }
// F = крок уперед; +/- = поворот; [ = запам'ятай стан; ] = повернись
```
*(твоя `recursive-growth`, моя `plant-a-garden`)*

### 8. Кільце як сигнал + поклик-відповідь
Кільце росте; коли його радіус переростає відстань до другого вузла — той відповідає
своїм, трохи тихішим. Множник <1 робить так, що розмова осідає в тишу сама:
```js
if (!r.answered && r.r >= r.reach){
  r.answered = true;
  const back = r.energy * 0.62;
  if (back > 0.07) pending.push({ node: r.target, energy: back, t: 20 });
}
```
*(`call-and-answer`)*

### 9. Практична дрібниця, що береже час
- **Перевірити синтаксис без браузера:** витягни скрипт і згодуй його `vm.Script` —
  кине помилку на поганому синтаксисі, нічого не запускаючи:
  ```
  node -e "new (require('vm').Script)(scriptText)"
  ```
- **Опублікувати як самодостатній Artifact:** прибери зовнішні `<html>/<head>/<body>`
  (їх додає обгортка), `<title>` — угорі файлу, все вбудуй інлайн. CSP блокує зовнішні
  хости, тож жодного CDN.
- **Дотик на мобільному:** `canvas{ touch-action:none }` + події `pointerdown`/
  `pointermove` (працюють і мишею, і пальцем одразу).
- **Адаптивність:** на `resize` роби `W = c.width = innerWidth` і перераховуй усе, що
  залежить від `W/H` (позиції, масштаби).
